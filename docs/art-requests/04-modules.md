# Pictures for the building modules, the Lark's parts and the sunstone cells

Modules are fitted into the buildings' sockets (each building level opens one), Lark parts go on the airship, and
sunstone cells are set into the sockets of good gear at Odile's bench. They all have small icons drawn in code for
now. These prompts are for proper pictures to take their place, in the same style as the gear in art request 02.

## How to make them

- Square, 512 × 512 (bigger is fine). The game shrinks them to 128 × 128.
- Save each as the file name given and send them in the chat. I'll put them in `assets/items/`.
- Paste **the style paragraph from `02-items.md`** ("Detailed HD pixel-art game item icon, in the same style as the
  curios on Quill's stall…") in front of each prompt below. These are fittings, not hand-held gear, so where that
  paragraph says "a little worn from use on a mining claim", that still fits: they're bolted to working buildings.
- Anything without a picture keeps its drawn icon.
